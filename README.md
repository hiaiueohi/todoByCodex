# サクッとToDo

スマホでの片手操作を最優先にした、インストール可能なToDoアプリです。タスクはブラウザ内に保存されるため、アカウント登録なしですぐ使えます。

## 使い方

`index.html` をローカルWebサーバーで開きます。VS Codeなら **Live Server** 拡張機能で `index.html` を開くのが手軽です。

スマホでは、公開したHTTPSのURLをSafariまたはChromeで開き、ブラウザのメニューから「ホーム画面に追加」を選ぶとアプリのように使えます。

## 主な機能

- 今日・今週・いつか、の3分類
- 何年先でも移動できるカレンダーと日付ごとのタスク表示
- 毎日・毎週・毎月の繰り返しタスク
- タスクの追加、完了、削除、完了済みの一括消去
- 今日の完了率
- ライト／ダークモード
- オフラインで開けるPWA対応

> データはこのブラウザ・端末だけに保存されます。端末間で同期したい場合は、次の段階でログイン／クラウド同期を追加できます。
